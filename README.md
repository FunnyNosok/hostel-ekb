# Хостелы ЕКБ — сайт

Простой статический сайт хостелов Екатеринбурга. Без сборки и зависимостей —
открывается двойным кликом по `index.html`.

## Структура

```
Hostel/
├── index.html        — каркас страницы (шапка, лента, список, подвал)
├── css/
│   └── styles.css    — все стили
├── js/
│   ├── data.js       — ДАННЫЕ: телефон, хостелы, цены, фото
│   └── app.js        — рендеринг карточек и списка из данных
└── assets/
    └── img/          — фотографии хостелов
```

## Как редактировать

Вся правка контента — в **`js/data.js`**:

- **Сменить телефон** — поля `SITE.phone` (для звонка) и `SITE.phoneDisplay`
  (как показывается). Обновится сразу везде: шапка, кнопки, подвал.
- **Изменить цену/адрес/описание** — соответствующее поле в массиве `HOSTELS`.
- **Добавить хостел** — скопировать любой объект в `HOSTELS`, поменять
  `id` (уникальный, латиницей), название, фото. Карточка в ленте и блок
  в списке появятся автоматически.
- **Фото** — класть в `assets/img/`, первый элемент массива `photos` —
  главное фото карточки, следующие два показываются в галерее.

`index.html` и `app.js` трогать при правке контента не нужно.
